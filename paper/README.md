# paper/ · journal-paper workspace

Kept alongside the code so the paper, the FYP report and the results never drift apart.

| File | What it is | Updated when |
|---|---|---|
| `PAPER_PLAN.md` | Target venue, story, outline, figures, related work, open questions | Venue decided (after Gate 1), outline changes |
| `CLAIMS_LEDGER.md` | Every number or claim the paper may use, with the evidence behind it | **Every time a result lands** (one line) |
| `WRITING_SESSION_BRIEF.md` | Start-up note for a separate writing session (what to read, rules) | Rarely |

Rule: the paper only states what the ledger supports, with the ledger's wording strength
(descriptive / exploratory / confirmatory). Confirmatory numbers enter the ledger only after the
locked run (after 10 Jan 2027).
